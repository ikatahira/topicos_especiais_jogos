Métricas e Análise

"O jogador se divertiu" não é uma métrica. Hoje é sobre transformar sensação em número — tanto no sensor quanto no sistema gamificado inteiro.

Prática do dia (30 min): da leitura bruta à métrica

Uma leitura de sensor sozinha costuma balançar (ruído). Hoje a dupla resolve isso na prática: em vez de imprimir um valor por vez, tira várias leituras seguidas e calcula a média — a primeira métrica de verdade construída a partir de dado bruto.

const int N = 10; int soma = 0; for (int i = 0; i < N; i++) { soma += analogRead(A0); delay(50); } int media = soma / N; Serial.print("Leitura media: "); Serial.println(media);

É simples, mas é exatamente o princípio por trás de qualquer métrica: dado bruto sozinho engana, dado agregado com critério conta uma história mais confiável.

Dois tipos de métrica

Engajamento

Como a pessoa se comportou

Mede envolvimento durante o uso, não o resultado final.

  • Tempo de sessão
  • Tentativas / retries
  • Fatores de fluxo (concentração, desafio, feedback — semana do SEGAE)
Resultado

O que mudou de verdade

Mede o efeito real, fora do momento de jogar.

  • Conhecimento antes/depois (pré e pós-teste)
  • Mudança de comportamento observada
  • Decisões corretas em situação real

Construindo um índice composto

Quando uma métrica sozinha não conta a história toda, junta-se várias num índice — como já vimos em duas referências:

Índice de Economia Limpa (EcoFarming, referência no índice) — combina receita + cumprimento de metas de sustentabilidade, pra não premiar só quem lucra mais.
Índice de exposição ao risco (artigo local, Nikolas/Geovani/Laura/Katahira/Jéssica — também no índice) — combina fatores de plataforma pra comparar risco de phishing de forma objetiva, não subjetiva.

O padrão dos dois: escolher 2-4 fatores que importam, decidir o peso de cada um, e somar de um jeito que ninguém "ganhe" só otimizando um fator sozinho.

Aplicando ao agronegócio

▣  Pro projeto final, evitar métrica única de pontuação. Um índice tipo "decisão certa + uso consciente de recurso" (como já está na tabela de pontuação da semana 1) já é, sem perceber, um índice composto simples.

◆  Se o produto final for demonstrado em evento, vale pensar numa métrica de engajamento simples pra coletar ali mesmo: quanto tempo a pessoa ficou, quantas rodadas jogou, se pediu pra jogar de novo — dado real sobre se a demonstração funcionou.
