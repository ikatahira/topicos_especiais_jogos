✏️ Atividades Práticas

🎯 Atividade 1: Gerador Procedural

Implementar gerador procedural em Unity usando Wave Function Collapse ou similar para criar dungeons/níveis.

📦 Entrega: Protótipo funcional + código comentado + GIF mostrando geração + análise de algoritmo

🎯 Atividade 2: Experimento IA Generativa

Usar Midjourney/Stable Diffusion para criar concept art de jogo. Documentar processo, resultados, limitações.

📦 Entrega: Portfolio de 10+ imagens geradas + prompts utilizados + análise crítica

🎯 Atividade 3: Ensaio Ético

Escrever ensaio sobre ética de IA generativa em games: copyright, jobs, criatividade, futuro.

📦 Entrega: Ensaio acadêmico 4-5 páginas argumentando posição fundamentada + referências
