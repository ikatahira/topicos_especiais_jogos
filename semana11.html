☁️ O QUE É CLOUD GAMING? ▼

Cloud Gaming (ou jogo em nuvem) é um modelo onde o processamento do jogo acontece em servidores remotos, não no seu dispositivo. Seu computador ou celular só recebe o vídeo comprimido e envia seus inputs de volta.

Imagine que o servidor é como uma sala de arcade gigante na internet. Você está em casa jogando controle, mas o videogame de verdade está em outro país.

💡 Analogia: É como Netflix, mas em vez de filmes, são jogos. A diferença é que você controla o que acontece na tela em tempo real.
INPUT: Você pressiona botão → sinal viaja até servidor → servidor processa → frame renderizado → stream de vídeo volta para você → você vê o resultado. Todo esse ciclo em milissegundos.
⚡ LATÊNCIA: O INIMIGO DO CLOUD GAMING ▼

Latência é o tempo entre você apertar um botão e ver a resposta na tela. Medida em milissegundos (ms). É o maior desafio técnico do cloud gaming.

Em jogos locais, a latência de input é tipicamente 1–5ms. No cloud gaming, você soma: tempo de upload do input + processamento no servidor + compressão de vídeo + download + descompressão. Isso facilmente chega a 40–100ms.

💡 Jogos como Rocket League ou CS:GO se tornam muito difíceis com alta latência. Jogos de aventura single-player quase não sofrem impacto.
TOLERÂNCIA POR GÊNERO: • RPG / Aventura → até 150ms OK • Plataformer → até 80ms OK • FPS competitivo → precisa de menos de 40ms • Fighting games → precisa de menos de 30ms
🎬 CODECS E STREAMING DE VÍDEO ▼

O frame do jogo renderizado no servidor precisa ser comprimido e enviado via rede em frações de segundo. Isso é feito por codecs de vídeo. Os mais usados em cloud gaming são H.264, H.265 (HEVC) e AV1.

O desafio: codecs tradicionais como H.264 introduzem artefatos visuais (borramento, pixelização) em cenas com muita ação. O AV1 melhora a qualidade mas exige mais processamento para encodar.

NVIDIA usa NVENC (hardware encoder) para H.265 ultra-rápido. Xbox Cloud usa H.264 para compatibilidade ampla. GeForce Now suporta AV1 com plano premium.

🎮 IMPACTO NO GAME DESIGN ▼

Cloud gaming não é só uma mudança de infraestrutura — ela muda como os jogos devem ser projetados.

Restrições a considerar: Evitar mecânicas frame-perfect. Evitar gêneros hiperdependentes de latência baixa (FPS competitivo). Considerar que o jogador pode estar no celular com touchscreen.

Oportunidades únicas: Mundos persistentes compartilhados por milhares de jogadores no mesmo servidor. Jogos com grafismo de console em qualquer dispositivo. Experiências únicas com processamento pesado no servidor (física avançada, IA complexa).

🌟 Exemplo real: Microsoft criou o Microsoft Flight Simulator onde parte do processamento do terreno do mundo inteiro fica nos servidores Azure — impossível localmente.

No navegador, pressione F para tela cheia. Se perceber muita pixelização, provavelmente sua conexão está abaixo de 15 Mbps. O GFN recomenda 25+ Mbps para 1080p estável.
