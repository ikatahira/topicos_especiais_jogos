Casos de Sucesso

Última semana do módulo: em vez de mecânica nova, hoje é sobre ler os exemplos reais que já foram catalogados — o quê especificamente fez cada um funcionar (ou não).

Prática do dia (30 min): dois sensores, um sistema

Fechamento técnico do módulo: juntar o sensor analógico (umidade do solo, semana 2) com o DHT11 (temperatura e umidade do ar, semana 8) num único sistema de decisão — dois dados diferentes informando a mesma lógica de alerta.

int solo = analogRead(A0); float tempAr = dht.readTemperature(); bool soloSeco = solo < 300; bool calor = tempAr > 30; if (soloSeco && calor) { // pior cenario: irrigar com prioridade digitalWrite(ledVermelho, HIGH); } else if (soloSeco || calor) { digitalWrite(ledAmarelo, HIGH); }

Esse é o tipo de lógica combinada que separa um alerta simples de um sistema de decisão real — dois sinais concordando pesam mais que um sozinho.

Aplicando ao agronegócio

▣  Dos 5 fatores, contexto local é o que mais separa um projeto genérico de um que realmente conecta com quem está jogando — é literalmente o motivo de trocar "agro genérico" por biomas e situações brasileiras reais.

◆  Antes de fechar o design do projeto final (próximos módulos), vale usar essa tabela de 5 fatores como checklist rápido — se 2 ou mais estiverem fracos, provavelmente o sistema não vai engajar como esperado.
